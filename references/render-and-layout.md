# 恢复渲染与运行后的场景图

## 从真实绑定追踪

找到实际对象上的 Renderer/Graphic/字体与材质，再解析纹理、Shader 与参数。不按相似资产名选图：同名图片可能属于 UI、透明辅助材质或其他变体。记录该绑定的实际启用条件；静态引用数只能帮助排序。

对照资源分层：原 APK 对象与字段 → 原导出 → 当前工程 → 最终重建包。文件字节相同只证明文件保留；导出遗漏、importer、压缩、颜色转换、GPU 采样与动态状态仍可能不同。

## Shader 是程序，不是材质占位符

按当前原包实际使用的图形程序/变体恢复所需部分：

- 属性名称、类型、默认值、HDR/Gamma 标记、纹理默认值与 ST；标记可能改变上传数值的颜色转换。
- 顶点输入及插值：POSITION/NORMAL/TANGENT/COLOR/UV、instancing 与对象/世界空间。
- UBO/常量偏移与矩阵声明；float4 数组并不必然获得 Unity 对矩阵类型的自动上传。
- fragment 的渐变/旋转、Ramp/MatCap、轮廓光/高光、透明/裁剪、雾等原公式及条件。
- Pass、LightMode、keyword、RenderQueue、Blend、Cull、ZTest/ZWrite、阴影与 depth/depth-normal 所需输出。
- 平台投影/裁剪、Y 翻转、深度范围与 reversed-Z。先确认 API 实际规则与编译后的程序，避免在包装层重复转换。

属性声明但未消费、sampler 绑定但未采样、ShadowCaster 缺失都应按活跃材质条件审查。Shader `isSupported=true`、无 magenta 或编译零错误不能证明原外观。

Blend 和输出应成对判断：预乘 RGB + One/OneMinusSrcAlpha 与非预乘 + SrcAlpha/OneMinusSrcAlpha 在特定条件可能等价；不要仅比较一个字段即宣称原因。顶点 COLOR 路径丢失是程序差异，但若实际网格恒白，该项未必造成当前像素差异。

比较实际被消费的最终通道与混合方程，并核实目标格式与后续读取；RGB 等价不自动推出 Alpha 等价，Alpha 差异也不自动影响最终只读 RGB 的输出。

## 动态视觉行为

核对 RenderTexture 谁创建、谁写入、何时相机渲染、谁执行 blur/blit、谁绑定输出及释放；资源文件存在不能替代执行链。

UI 检查 Sprite mesh/UV/packed padding、九宫格、Canvas/RectTransform、布局驱动、安全区、字体/SDF 属性、状态激活和文本刷新。PNG 相同不意味着按钮大小/边框一致；弹窗类能绑定不意味着 Show 方法有效。

Tween/动画/协程控制的颜色、透明度、位置、开关和销毁要纳入语义恢复。明确哪一步初始化、何时触发、最后有效回调是什么。

## 原场景保留与运行图

比较序列化 fileID、父子关系、组件、transform、引用及已记录的官方库 GUID 映射。只允许有依据的映射/迁移，不随意重写整个场景。

若序列化一致，沿正式启动后的变换链定位：

1. 数据创建与实例化、SetParent/worldPositionStays、位置/旋转。
2. 内容旋转、根节点缩放/居中、局部/世界 bounds 和碰撞体。
3. 偏移、路径/spline、相机 Brain/虚拟相机、透视/正交与分辨率分支。
4. 安全区、CanvasScaler、布局重建时机、UI/视觉对象的后续生命周期。

该顺序用于寻找依赖，不要求每个项目存在全部步骤。先确认失败分支是否真的执行：正交 fit 不一定影响透视相机；首关无机关不能用绳索缺口解释普通点击。

父子变换争议可用给定前置状态列出操作前后的 local/world 数值，检验空间契约；该计算属于静态推导，不能标成运行观察。

## 对照实验

先核对设备、API、分辨率/方向、存档、关卡、相机、模型分支与事件阶段；不同条件不作为修复前后证据。核实图像内容，文件名不是进关凭证。

关卡编号不能只看 HUD 文本或 `index` 日志：核对进度键、排序表、原始数据索引、关卡资产身份/哈希与必要的难度/动态选择分支，确认它们如何映射到实际加载内容。调试种子、跳关与覆盖数据另列偏离；映射未闭合时标记未知，不能凭显示编号宣称同关或错关。

静止物体/界面使用明确 ROI 或几何指标；运动对象按到达/碰撞/动画阶段比较，避免整帧像素差被时序污染。记录误差定义和通道范围，MAE 不是恢复百分比。

每次只隔离能解释目标差异的变量。先恢复有依据的算法/输入/元数据，避免通过调灯、曝光、材质值和重画贴图叠加补偿。最终 APK/Player 中需确认目标字段/程序真正被消费；只改源码不算完成。

Built-in、URP、HDRP 与引擎版本属于当前项目事实，不从参考项目照搬。导入自动生成默认管线/GlobalSettings 或重写设置时，核实与原绑定的差异，不能将“Unity 修好了”视为等价证明。
